# Scope T-M3 — competing representations

The article no longer compares isomorphism-test wall-clock; it compares the
*geometry* each representation induces on hypergraph space. A competitor is any
isomorphism-invariant map `H ↦ fingerprint(H)` with a natural distance on
fingerprints, yielding its own matrix `D_rep` that runs through the same
correlation study and the same applications. This scope wires four, each a
distinct geometric philosophy so they do not collapse into one another:
hypergraph-WL (vertex-neighbourhood counting), HyperCOT (mass transport, a metric
by construction), Hyperedge Portrait Divergence (hyperedge-path tensors), and —
as the deliberate *contrast*, not a strawman — nauty canonical forms over the
Levi reduction, included precisely to show that iso-only canonical labelling
yields no navigable geometry. NetLSD is an optional spectral fifth.
