## A. Formal statements

- **A1. Def. (labelled hypergraph)** — `P_A` Def. 1.1 `def:hypergraph`. `H=(V,E,ℓ_V,ℓ_E)`; `E` is a set of **pairs** `(ℓ,e)`, `e⊆V`, `1≤|e|`; **no two members share the same `(ℓ,e)`** (`SparseHypergraph` dedups by `(label, member-set)`). Parallel hyperedges with *different* edge labels are legal; same-label duplicates are not. Primal graph = co-occurrence graph. *Definitional.*
- **A2. Standing assumption** — `P_A` Ass. 1.4 `ass:standing`. `H` connected in its primal graph (B11; disconnected inputs rejected upstream); `k ≥ max(2, max_e|e|)` (`required_k`); both compared hypergraphs share `(Σ_V,Σ_E)`, the same `k`, and the same structural depth `h` (default 3). **Every statement below inherits these.**
- **A3. Def. (alphabet `Σ_HG(k)`, decoder S2H)** — `P_A` Def. 1.6 `def:s2h`. Tokens `P[i]`,`N[i]` (`1≤i≤k`), `V[ℓ;i;j;λ_1..λ_j]`, `C[ℓ;i]`, `W`. "`StH(w;k,ℓ_0)` … **is a total deterministic function (closed-alphabet invariant)**." Size, trivial vocabulary (`src/isalhg/metric_space/metrics/information.py::alphabet_size_isalhg`): **`|Σ_HG(k)| = k(k−1)/2 + 3k + 1`** (V `k(k−1)/2`; C, P, N `k` each; `W` 1). Labelled vocabularies multiply V and C by the label-combination space; the function returns the **unlabelled** count only. *PROVED (totality).*
- **A4. Proposition (Closure)** — `M_prep` `prop:closure`: "Every string `w ∈ Σ_HG*` decodes to a valid hypergraph." Proof: every token executable in every reachable state; CDLL circular and never empty so `P_i`/`N_i` always defined; pointer aliasing only shrinks an edge's support; `V_{i,j}` always contains ≥1 fresh node so never duplicates; `C_i` skips duplicates; `W` inert. *PROVED* — the only published statement of totality.
- **A5. Lemma (progress & termination)** — `P_A` Lem. 2.1 `lem:termination`. From every non-terminal reachable encoder state ≥1 candidate exists; every execution of either policy terminates after **exactly `m` structural emissions** with `dom μ = V`, `C = E`. Primal connectivity is used exactly here. *PROVED.*
- **A6. Lemma (decoding correspondence / round-trip)** — `P_A` Lem. 2.2 `lem:roundtrip`. For any seed and any execution path, `StH(w_pre;k,ℓ_V(s))` matches the encoder state on (i) vertices+labels via `μ`, (ii) edges `{(ℓ,μ(e))}` all distinct, (iii) CDLL payload sequence and pointer payloads. Hence `StH(w;k,ℓ_V(s)) ≅ H` via `μ^{-1}`. *PROVED.*
- **A7. Theorem (forward / soundness)** — `P_A` Thm 2.3 `thm:forward`: *for any branch policy and any iso-invariant seed rule, `F(H_1)=F(H_2) ⇒ H_1≅H_2`*. Holds for `greedy_min`, `greedy_min_nbrdeg`, `greedy_min_complete` alike; needs **no** equivariance. ***PROVED, unconditional*** — this is what makes greedy variants one-sided-sound heuristic fingerprints.
- **A8. Greedy incompleteness (counterexample)** — `P_A` Ex. 3.1 `ex:edgeorder` + Prop. 3.2 `prop:greedyfalse`. `n=4, m=4, k=3`, unlabelled, `E={{1,3},{0,1,3},{0,2,3},{1,2}}` (primal graph `K_4`, `ξ_3(v)=(3,0,0)` everywhere, every arity-2 V-candidate ties on `π=(1,1,0,(0),(6,0,0))`). Order `e_0..e_3` → `V[0;1;1;0];V[0;1;1;0];N[1];V[0;2;1;0];N[2];P[3];C[0;3]`; rotation `(e_1,e_2,e_3,e_0)` → `V[0;1;1;0];V[0;1;2;0,0];N[1];P[2];C[0;2];P[2];C[0;3]`. Same abstract hypergraph, both 7 tokens. Prop.: `w*_greedy` (`greedy_min`, `greedy_min_nbrdeg`, and any min-edge-id variant **incl. `exhaustive`**) is not a function of the abstract hypergraph ⇒ reverse direction **false**, and Levenshtein on `w*_greedy` is not well defined on isomorphism classes. ***REFUTED for the greedy variants*** (Python + C++ verified; pinned `tests/unit/core/test_greedy_min_complete.py`; raw data `tta_minimal_counterexample.json`).
- **A9. Seed-label deficiency of the bare string** — `P_A` Ex. 3.3 `ex:seedlabel` + Rem. 1.12 `rem:augment`. With `|Σ_V|=2`: `H_a` two vertices labelled `(0,0)` + one edge, `H_b` same with `(1,0)`. `w*(H_a)=w*(H_b)=V[0;1;1;0]` under **every** variant, yet `H_a≇H_b` — the string never records the **seed vertex's own label** (V carries only *new*-vertex labels; C carries none). ***REFUTED for the bare string on labelled inputs*** (machine-verified false positive pre-T-TAb). Fix: **augmented fingerprint** `F_pol(H) = (ℓ_max(H), w*_pol(H))` (`P_A` Def. 1.11 `def:canonical`), `ℓ_max` = common label of all seeds; serialised `b"{label}|{w*}"`, prefix omitted iff `|Σ_V|=1`. **Load-bearing for "KB as labelled hypergraph": compare `F`, never bare `w*`.**
- **A10. Prop. (why the historical tests passed)** — `P_A` Prop. 3.4 `prop:orderpreserving`. For *order-preserving* isomorphisms (the `permute` oracle) the greedy **is** equivariant. *PROVED*; delimits the blind spot.
- **A11. Equivariance chain** — `P_A` Lem. 4.1 `lem:seeds` (seed-set equivariance `S(H_2)=φ(S(H_1))`, `ℓ_max` equal), Def. 4.2, Lem. 4.3 `lem:equivariance` (step), Lem. 4.4 `lem:forest` (execution-forest bijection: tie-complete completions equal on corresponding states), Thm 4.5 `thm:backward` (`H_1≅H_2 ⇒ F_c(H_1)=F_c(H_2)`; `w*_c` invariant under vertex relabelling **and** edge reordering). *All PROVED.*
- **A12. THEOREM A** — `P_A` Thm 5.1 `thm:main`: *under A2, for connected **labelled** hypergraphs encoded with the same `k` and vocabularies,* **`F_c(H_1) = F_c(H_2) ⟺ H_1 ≅ H_2`**; over the trivial vertex vocabulary this reduces to `w*_c(H_1)=w*_c(H_2) ⟺ H_1≅H_2`. Hypotheses: A2 **and** the tie-complete policy (`tie_branch=True`, C++ variant 7). ***PROVED*** (⇒ Thm 2.3, ⇐ Thm 4.5). Empirical arms: 150/150 relabel+reshuffle invariance; `w*_c`-equality = pynauty Levi decision exactly (Hypothesis, 25 examples, seed 0).
- **A13. COROLLARY A (metric)** — `P_A` Cor. 5.2 `cor:metric`: `d_I(H_1,H_2) = d_Lev(w*_c(H_1), w*_c(H_2))` **on the token sequences** (trivial vertex vocabulary; in general compare augmented fingerprints, e.g. `d_I + 1[ℓ_max differs]` or seed-label-prefixed strings) is a **metric on isomorphism classes of connected hypergraphs of arity ≤ k**. Non-negativity/symmetry/triangle from `d_Lev`; identity of indiscernibles from Thm A. ***PROVED.*** With greedy variants it is at best a pseudometric on a fixed presentation convention. Implementation: **raw (un-normalised) token-level Levenshtein via `rapidfuzz`**, `src/isalhg/metric_space/distances/isalhg_levenshtein.py` (OQ-D: raw primary, normalized/token-weighted = at most one ablation table).
- **A13b. Remark (label-conditional metric FAMILY)** — `docs/article/theoretical/stability.md` §1. The correct name is the **family** `{d_I^{k,h,Σ}}`: for each fixed `k`, structural depth `h`, and vocabulary `Σ=(Σ_V,Σ_E)`, `d_I^{k,h,Σ}` is a metric on isomorphism classes of connected `Σ`-labelled hypergraphs of arity ≤ `k`, where isomorphism is **label-preserving**. Under `Σ=(⊥,⊥)` this reduces to plain structural isomorphism. ***Members from different `(k,h,Σ)` triples are metrics on different domains and must not be pooled or compared in one distance matrix or MDS embedding.*** Domain restriction: `d_I` is defined only for `n ≥ 1`; the empty hypergraph is excluded (`DegenerateHypergraphError`). **The normalized ablation `edit/max_len` is a *dissimilarity*, not a metric — it violates the triangle inequality** (Marzal & Vidal, IEEE TPAMI 15(9), 1993; pinned witness triple in `tests/unit/metric_space/test_isalhg_levenshtein.py::TestNormalizedNonMetric`). *Directly binding on a median construction: any Fréchet/Steiner argument needs the triangle inequality, so the normalized variant is disqualified, and all `N` knowledge bases must share one `(k,h,Σ)`.*
- **A14. Prop. (automorphism-coherent ties)** — `P_A` Prop. **6.1** `prop:coherent`. A tie is *coherent* if for every `e,e'∈T(σ)` some `ψ∈Aut(H)` fixing `dom μ` pointwise has `ψ(e)=e'`. If every reachable tie is coherent (recursively), all tied branches return equal completions, so `w*_greedy = w*_c` on such `H`. *PROVED.* This is the object everything calls **"Prop 6.0"** — see F1.
- **A15. Stabiliser-orbit pruning (value-preserving)** — `P_A` §8 item 3 (D-TA2), corollary of A14: collapsing each orbit of the point-stabiliser's action on `T(σ)` to one representative **returns the same `w*_c`**. *PROVED*; **not implemented** in production. The *only* sanctioned speedup.
- **A16. Lemma (admissible pruning)** — `P_A` Lem. **6.3** `lem:pruning`. Refining `T(σ)` by any iso-invariant key `ρ` preserves Lem. 4.3/4.4, Thm 4.5, Thm A. *PROVED* — but **forbidden by D-TA2**: a κ-min over a proper subset of `T(σ)` need not equal the κ-min over `T(σ)`, so `ρ`-refinement **forks the definition of `w*_c`**. The lemma itself notes `*_wl_pruned` id-dependent pruning is **not admissible**. Pin: `tests/unit/core/test_wstar_c_frozen.py`.

Assumption (connected domain, D-CONN1)** — `P_B` Ass. 1 `ass:connected`: "`w*_c` and `d_I` are defined only on connected inputs; this is consistent with the alphabet (`V_{i,j}` has `i ≥ 1`, so every instruction attaches to an existing node, and **the S2H-reachable set is exactly the connected hypergraphs**)." *Stated as an assumption + one-line justification; **no numbered lemma proves the "exactly" claim** in any `.tex`* (see E2).
- **A18. Lemma B0 (path normalization)** — `P_B` Lem. 2 `lem:b0`. For connected `H,H'` with `HGED=t` there is an edit path with (P1) every intermediate connected, (P2) total Qin cost exactly `t` (no inflation), (P3) no intermediate arity `>k`. *PROVED* (three-substep reordering).

- **A20. Def. (tie-set transparency = H1–H3)** — `P_B1` Def. 1 `def:transparent`. **(i) seed preservation** `v_0 ∈ S(H⊕e)`; **(ii) key-crossing freedom** — at every reachable state, every κ-comparison between a *perturbed* candidate (a member in `N_r[e]`, `r=3`) and an unperturbed one resolves identically in `H` and `H⊕e`; **(iii) argmin-seed preservation** — `v_0` remains the κ-minimum seed in `H⊕e`. Under (i)–(iii) the two search trees are isomorphic outside the `N_1[e]` window and the strings agree outside `O(kΔ)` emission positions, giving `s(e) ≤ (2k+1)(1+Δ) + R(e) + T_span(e)`; under (iv)–(v), `s(e)=O(kΔ)`. ***CONDITIONAL*** (H1–H3 for the structure, H4–H5 for the `O(kΔ)`). ⚠ the constant `(2k+1)(1+Δ)` is **retracted** — see F3.

## B. Complexity facts

- **`w*_c` cost is worst-case exponential** in tie multiplicity: κ-min over the full residual tie set `T(σ)` × all label-respecting orderings, per seed, over the whole iso-invariant seed set. `P_A` §8 item 2: the tie-complete C++ twin costs **3.8–18.9×** the single-branch greedy default on the design fixtures. `M_prep` `rem:hardness`: hypergraph iso ≡ graph iso, so computing `w*` is at least as hard as GI; the search multiplies up to `n` seed runs by branch counts bounded by `∏ j!` over V emissions. No polynomial-time algorithm should be expected.
- **Measured wall-clock** (i7-13700KF, `-O3 -march=native`; `P_A` §7 item 6): Fano **6.41 ms** (538× the Python reference), STS(9) **137 ms** (961×; 132 s in Python), cyclic `C_13` **270 ms**, GQ(2,2) **1.09 s**; random `n ≤ 12` median ≤ 0.7 ms, max 43.7 ms.
- **DNF / blow-up tail** (`P_PR` §4, branch budget `5·10^4` expansions): **complete binary trees of depth ≥ 5 (`n ≥ 63`) exceed it** — their *all-coherent* tie structure blows up the **unpruned** search (the concrete cost of D-TA2's freeze, and the motivation for A15). At density ≈1.0 and `n ≥ 48`, random draws frequently exceed it too (pendant symmetries). Repo frontier (`DEVELOPMENT/README.md`, S7): `k=3` feasible to `n ≈ 24` at low density; `k=5` only at `n=8`; `k=7` and `k=10` measured infeasible; STS(15/19) pristine `w*_c` > 900 s on rigid instances.
- **Measured single-edit sensitivity** (`P_PR` §4, density 1.5, medians): `n=12` add-incid. 31 / del-edge 26 / ins-vertex+edge 31 / rem-incid. 28 vs `kΔ=21`; `n=32` → 145 / 131 / 122.5 / 115.5 vs `kΔ=21`. Grows ≈**linearly in `n`** for every edit type and approaches the string length (`|w*_c| ≈ m+M ≈ 196` at `n=32`). Dominant mechanism at constant density is **avalanche**, not drift.
- **Budget/timeout in code**: `canonical_string(..., max_expansions: int | None = None)` (`src/isalhg/core/canonical.py:139,352`), `None`/`0` = unlimited; C++ throws `CanonicalizationTimeoutError` when exceeded (`_native/include/isalhg/canonical.hpp:46`).
- **C++ engine**: `src/isalhg/core/_native/` (`canonical.cpp`, `h2s.cpp`, `s2h.cpp`, `cdll.cpp`, `structural_tuples.cpp`, `wl.cpp`, `thread_pool.cpp`, `bindings.cpp`). `AlgorithmVariant` (verbatim from `canonical.hpp`): `0 GreedyMin`, `1 GreedySingle`, `2 GreedyMinInplace`, `3 GreedyMinWlPruned`, `4 GreedyMinInplaceWlPruned`, `5 GreedyMinNbrDeg`, `6 GreedySingleNbrDeg`, **`7 GreedyMinComplete`** — "the only variant whose `w*` is a complete isomorphism invariant". Default backend `"cpp"`; `backend="python"` is the differential reference (byte-identical on 3,344/3,344 per-seed comparisons). Seed loop parallelised over a persistent thread pool.
- **Arity cap `k`**: `required_k(H) = max(2, max arity)`; corpus-wide max via `isalhg_levenshtein.py::_resolve_corpus_k`. `k=10` (B12) is the **alphabet default**, not a runtime cap. Two canonical strings are comparable **only at the same `k`** (`M_prep` `rem:params`; CLAUDE.md invariant 7).
- **Connectedness (D-CONN1)**: `canonical_string`/`canonical_fingerprint` **reject** disconnected inputs — `DisconnectedHypergraphError` (`src/isalhg/errors.py:48`), enforced in C++ too. Reason: A5's progress argument needs primal connectivity to guarantee a V-candidate whenever `dom μ ≠ V`. Datasets restrict to the LCC. `M_prep` `rem:params`: "a per-component encoding with a lexicographic merge is the natural extension but is not developed here."
- **S2H is linear-time and total**: one VM step per token, no rejection on alphabet-valid input (rejection happens earlier in `instructions.py::validate`, e.g. pointer index > `k`, or `i+j > k`). `C` is idempotent, `W` inert, `P/N` always defined (circular CDLL).

## C. What the theory says about **labels**

1. **Theorem A covers labelled hypergraphs.** `P_A` Def. 1.1 defines `H` *labelled* from the start and Thm 5.1 is stated "for connected **labelled** hypergraphs encoded with the same `k` and vocabularies". Nothing in the proof is unlabelled-specific.
2. **Where labels enter `w*_c`.** (a) emitted tokens — `V[ℓ_E;i;j;λ_1..λ_j]` carries the edge label and the new-vertex labels, `C[ℓ_E;i]` the edge label; (b) the cascade key prefix **`π(e,d) = (i, j, ℓ, Λ(e), η_h(e))`** (`P_A` Def. 1.8), `Λ(e)` = ascending tuple of labels of the unmapped members — labels compared as **ints**; (c) branching is over **label-respecting orderings** only (ascending label sequence; all permutations within a label class); (d) the seed cascade's first rung is **max vertex label**, then max primal degree, then lex-max descending neighbour-degree list (`P_A` Def. 1.11(a), T-M0).
3. **Label semantics do not survive canonicalization — only label identity does.** `LabelVocabulary` (`src/isalhg/datasets/schemas.py`) maps semantic strings → lexicographically sorted contiguous ints at dataset construction; only ints reach `core/`. ⚠ **`LabelVocabulary.fit(items)` still raises `NotImplementedError("deferred to Phase 6 labelled-loader milestone")`** (`schemas.py:134`); every corpus to date uses `LabelVocabulary.trivial()`, so the labelled code path is **proved but empirically unexercised**.
4. **The seed label is not in the string** ⇒ `F(H)=(ℓ_max(H), w*_c(H))`, serialised `b"{label}|{w*}"`, prefix omitted iff `|Σ_V|=1`. On labelled inputs `d_I` must run on the **seed-label-prefixed** token sequence (or add `1[ℓ_max differs]`, Cor. A). Comparing bare `w*` on labelled inputs is a **false positive** (A9).
5. **Alphabet size grows with the vocabulary** — `alphabet_size_isalhg(k)` returns only the unlabelled `k(k−1)/2+3k+1`; its docstring says V and C counts "expand by a factor of the label combination space". Any bits/compactness claim on labelled KBs has **no implemented estimator**.
6. **Edge multiplicity** — `E` is a set of `(ℓ,e)` pairs, so two facts over the same argument set are representable iff they carry different edge labels; same-label duplicates are silently deduplicated by `SparseHypergraph` **and** by `C_i` (no-op if the edge exists).

## E. What supports / threatens a median–consensus-string construction

- **E1. Closed alphabet (SUPPORTS).** `Σ_HG(k)` is closed and S2H is **total and deterministic** (A3, A4). Every finite token sequence is a legal word and decodes. No syntactic feasibility constraint on a candidate median string.
- **E2. Every decoded string is CONNECTED (SUPPORTS).** Induction: the VM starts one-vertex; `C_i` adds no vertices; `V_{i,j}` attaches `j` fresh vertices inside an edge containing `i ≥ 1` existing ones. Consequence: the S2H-reachable set is **exactly** the connected hypergraphs (A17). ⚠ *Provenance*: an **assumption with a one-line justification** in `P_B` `ass:connected`, and a **proof sketch** in `figures/F3-decoding-corridor.md` §2 / `T-M5m.md`. **Not a numbered lemma in any `.tex`.** Any article leaning on it should promote it.
- **E3. Alignment paths stay decodable (SUPPORTS, with a caveat).** A31: every intermediate on an optimal Levenshtein alignment path between two canonical strings lies in `Σ_HG(k)*` and decodes to a connected hypergraph of arity ≤ `k`. Status **EMPIRICAL PIN + sketch** (62/62 decode, 62/62 connected). Depends on `d_I` being **token-level**, not on the ASCII serialization — which is how `isalhg_levenshtein.py` implements it.
- **E4. Intermediates are NOT canonical (THREATENS).** Measured: **only 10/62 intermediates are canonical — exactly the 2 endpoints of each of the 5 paths; no interior point of any geodesic is canonical.** Precisely: `Σ_HG(k)*` is the *ambient* string space and the canonical image `w*_c(𝓗)` is a **sparse subset** of it. `H2S∘S2H` is idempotent only on that image — `w*_c(S2H(w*_c(H))) = w*_c(H)` follows from A6 + Thm 4.5, but for an arbitrary `w`, `S2H(w) ≅ H_w` and `w*_c(H_w)` is the canonical representative of `H_w`'s iso class, in general a **different string of different length** from `w`. Consequences for a median: two constructions must not be conflated — **(a)** the ambient Steiner string `argmin_{w ∈ Σ_HG(k)*} Σ_i d_Lev(w, w*_c(H_i))`, which decodes to a hypergraph but is not `w*_c` of anything in general; and **(b)** the genuine Fréchet median over isomorphism classes `argmin_H Σ_i d_I(H, H_i)`, for which (a) is only a relaxation. Scoring (a) against (b) requires re-canonicalising `S2H(w)`, and **no result anywhere in the proofs relates `d_Lev(w, w*_c(H_i))` to `d_I(S2H(w), H_i)`**. This gap is the central formal risk. The measured STS7 → TightCycle3 walk (`d_I`=10) **contracts to a 3-vertex bottleneck and rebuilds** rather than morphing (`figures/F3` §3) — a geodesic is not a structural morph.
- **E5. Avalanche/drift threaten outlier filtering and consensus stability.** A cost-1 incidence edit can move `d_I` by `Θ(n)` (drift, `prop:orphan`), and a tie/seed perturbation rewrites most of the string (`s=O(mk)`, avalanche); measured median `s(e)` grows ≈linearly in `n` and approaches the string length by `n=32` (B above). So "small disagreement between KBs ⇒ small `d_I`" is **false in general**; only `d_I = 0 ⇔ ≅` is proved. *Counterweight worth keeping*: on the seven-regime G2 profile (`theoretical/geometry.md` §6) IsalHG's single-edit IQR is **2.0–8.0 tokens vs nauty-Levi's 10.0–20.0** (ratio 1.25–9.5×) with `heavy_tail_frac = 0.000` in **all seven** regimes — so `d_I` is *comparatively* well behaved even where it is not Lipschitz.
- **E6. No existing median/consensus code.** Exhaustive grep of `src/`, `scripts/`, `experiments/` for `median|medoid|consensus|steiner|barycent|centroid|fermat|weiszfeld`: `median` hits are `statistics.median` / `np.median` runtime statistics only; `Steiner` occurs only in dataset names (Steiner triple systems); `KMedoids`/PAM is **sample-restricted** (representative must be an input element) — *not* a generalized median; `consensus`, `barycent`, `fermat`, `weiszfeld` have **zero hits**. **No generalized/Steiner median-string construction exists in this repository**, and `docs/article/RELATED_WORK.md` carries **no** median-string / consensus-string / Fréchet-mean citations.
- **E7. Available substrate** (`src/isalhg/metric_space/`): `distances/isalhg_levenshtein.py` (`d_I`, raw Levenshtein via rapidfuzz), `distances/hged.py` (exact HGED oracle, bespoke Qin op-set), `distances/qin_hged.py` (Qin cost model, no oracle); representations `wl.py`, `nauty_levi_edit.py`, `hpd.py` + `_hpd_vendor.py`, `netlsd.py`, `hypercot.py`, `degree_seq_l1.py`, `size_l1.py`; metrics `geometry.py` (ν, Gram spectrum, D̂), `embedding.py` (MDS/SMACOF, stress-1), `association.py` (Spearman/Pearson, hubness skew), `information.py` (fixed-width bits, compression ratio); plus `base.py` (`HypergraphDistance` ABC) and `registry.py`.
