# Scope T-M3 — competing representations

The article compares the *geometry* each representation induces on hypergraph
space and what that geometry lets you do. A competitor is any
isomorphism-invariant map `H ↦ fingerprint(H)` with a natural distance on
fingerprints, yielding its own matrix `D_rep` that runs through the same
applications, the same geometry table (`D̂`, `ν`, concentration), and the
capability matrix — the D-ART2 axes; the v2 HGED-correlation head-to-head is
retired. This scope wires five, each a distinct geometric philosophy so they do
not collapse into one another: hypergraph-WL (vertex-neighbourhood counting),
NetLSD (spectral heat trace — full member since D-ART2, the guaranteed
at-scale baseline), HyperCOT (mass transport, a metric by construction;
`O(n³)`/pair, run where feasible with the limit stated), Hyperedge Portrait
Divergence (hyperedge-path tensors), and — as the deliberate *contrast*, not a
strawman — nauty canonical forms over the Levi reduction, whose
avalanche-everywhere sensitivity profile is *measured* (T-M5g) to show that
iso-only canonical labelling yields no navigable geometry.
